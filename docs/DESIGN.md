# Design

Design principles, UX constraints, and the design token system for Stablerail.

## Design System

The unified design system reference lives at [`docs/design-docs/design-system.md`](design-docs/design-system.md). It covers:

- Color tokens (core palette, status triplets, chart palette, chain/token brand colors)
- Typography scale (display, headline, caption, micro, nano)
- Shadow and radius tokens
- Component presets (`lib/styles.ts`, `lib/brand-colors.ts`)
- Badge variants (pass, flag, block, info)
- How-to guides for adding new chains, tokens, and status variants
- Banned patterns and enforcement rules
